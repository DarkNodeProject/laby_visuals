# LabyMod Visuals Pack

Сборник конфигураций и визуальных улучшений для LabyMod 3. Включает настройки Item Radius, Auto Swap и другие популярные визуальные моды для Minecraft.

## 📦 Содержимое

- Готовые конфиги для LabyMod 3
- Визуальные настройки для PvP
- Item Radius + Auto Swap
- Оптимизированные пресеты

## 🚀 Установка

1. Скачайте архив из раздела **Releases**.
2. Распакуйте содержимое в папку с LabyMod.
3. Запустите файл `labyvisuals.exe` для применения настроек.
4. Перезапустите LabyMod.

## 🔒 Безопасность

Все файлы проверены на вирусы. Если антивирус срабатывает — это ложное срабатывание, связанное с модификацией конфигурационных файлов.
